## 🎯 РЕКОМЕНДАЦИИ ПО ИНТЕГРАЦИИ

### Стратегия
Поскольку все ветки находятся на одном коммите и содержат одинаковые файлы, **интеграция сводится к:**

1. **Взять role-01 за основу** — единственная ветка с полной архитектурой
2. **Восстановить удалённый функционал:**
   - Вернуть KeyFragment из role-01 (перекрыть role-03)
   - Вернуть DashboardFragment с навигацией (перекрыть role-06)
3. **Реализовать недостающий функционал:**
   - BookingFragment — форма бронирования с валидацией
   - HotelInfoFragment — карта отеля, контакты
   - ServicesFragment — адаптер услуг, фильтрация
   - PaymentFragment — таймер, эмуляция платежа
   - ReviewsFragment — Room, список отзывов
4. **Добавить зависимости:**
   - Room Database (для отзывов)
   - Maps SDK (для карт)
   - WebView (для меню ресторана)

### План работ
1. Создать интеграционную ветку от `feature/role-01-teamlead-architecture`
2. Применить патчи для восстановления удалённого кода
3. Реализовать недостающие функции
4. Протестировать сборку
5. Влить в `main`
